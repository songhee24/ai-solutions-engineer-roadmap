# Раунд 6. Сворачиваемые карточки тем

## Зачем

Дословно: «hard to read when open english». Этап рендерился целиком раскрытым — в треке английского
это шесть тем со всеми блоками, 18 ресурсов по четыре строки, задания и поля заметок. Стена текста,
которую нельзя просмотреть глазами.

## Решения

| Решение | Почему |
|---|---|
| Раскрывает **клик по названию**, не отдельная стрелка | Крупная цель, нельзя промахнуться по чекбоксу |
| Название было `<label for>` чекбокса — стало кнопкой | ⚠ Клик по названию больше не отмечает тему пройденной. Зато нельзя случайно закрыть тему, пытаясь её прочитать |
| Чекбокс получил свой `aria-label` | Взамен потерянного ярлыка — для скринридера |
| Состояние раскрытых тем **сохраняется** | Как уже сделано для этапов; ездит в экспорте JSON |
| Кнопки «Раскрыть/Свернуть всё» управляют и темами | Иначе массово раскрыть было бы нечем |

## В свёрнутом виде остаётся

Чекбокс, название, теги и **сводка о содержимом**: «3 ресурса · порядок действий · пример · задание».
Карточка остаётся информативной, а этап читается как компактный список.

## Отдельно починены переходы

«Продолжить обучение», ссылки из блока «Сейчас/Далее/Позже» и «Показать темы» в диагностике теперь
раскрывают именно ту тему, к которой ведут — иначе прокрутка приводила бы к свёрнутой карточке.
При активном поиске или фильтре совпавшие темы раскрываются сами.

## Обратная совместимость

Старый экспорт JSON без поля `openTopics` импортируется как прежде — есть отдельная проверка.
