# Раунд 5. Липкая панель разделов и починка программной прокрутки

## Зачем

Разделы были доступны только тремя якорями в шапке героя — при прокрутке попасть в нужное место
было нечем.

## Что сделано

Семь табов под шапкой: Сейчас · Диагностика · Карта · Математика · Английский · Tutorial hell ·
Вакансии. Активный подсвечивается при прокрутке. Табы треков заодно раскрывают карточку — иначе
переход приводил бы в свёрнутый блок.

## Два бага подряд, и второй интереснее первого

**Первый.** Клик по табу трека раскрывал трек, но не прокручивал. Причина: `renderStages()`
заменяет узел, к которому браузер собирался прыгнуть по якорю. Починено перехватом клика:
сначала перерисовка, потом прокрутка вручную.

**Второй, настоящий.** После починки прокрутка всё равно не работала. Диагностика показала, что
**в браузере Akara программная прокрутка молча не срабатывает вообще**:

```
window.scrollTo(0, 0)                  → scrollY остаётся 5
documentElement.scrollTop = 800        → остаётся 5
node.scrollIntoView({behavior:...})    → страница не двигается
```

Страница при этом прокручиваемая: `scrollHeight` 12801 против `clientHeight` 783.

Решение — общая функция `scrollToNode`: пробует обычную плавную прокрутку, через 400 мс проверяет,
сдвинулась ли страница, и если нет — прыгает мгновенно, вручную вычитая высоту липкой шапки.
Ею пользуются все три места, где была прокрутка: панель разделов, ссылки из «Сейчас/Далее/Позже»
и кнопка «Продолжить обучение».

Замер после фикса: `scrollY 0 → 2806`, верх трека на `y=124` при шапке `112`.

## Инцидент с чужим браузером

По ходу раунда выяснилось, что час проверки ссылок прошёл **в браузере коллеги**. Причина:
имена «Browser 1/2/3» раздаются по порядку подключения и переезжают между устройствами — один и
тот же deviceId за день побывал всеми тремя.

Проверенный способ определить своё окно, не потревожив чужие: Akara закрывает Chrome полностью,
`pgrep -f "Google Chrome"` даёт 0, всё оставшееся в списке — чужое. Поле `isLocal: true` при этом
**врёт** — оно стояло у окна на чужой машине.

⛔ `switch_browser` использовать нельзя: он показывает попап во всех подключённых окнах.

Записано в память `chrome-browser-identity-by-deviceid`.

## Чем проверяли

50 автопроверок, ноль ошибок консоли. Живая проверка настоящим кликом мышью в окне Akara.
