# Раунд 9. Отзывы и оценки

## Зачем

«Можно ли сделать систему оценки моего сайта? Мало ли кто-то найдёт, и я попрошу его поставить
оценку и написать отзыв».

## Ограничение, которое определило решение

Сайт статический, бэкенда нет. **Оценка в `localStorage` бесполезна** — она осядет в браузере
посетителя, и владелец её никогда не увидит. Нужно внешнее хранилище.

## Рассмотренные варианты

| Вариант | Плюс | Минус |
|---|---|---|
| GitHub Discussions через giscus | Живые отзывы, ноль бэкенда, спам режется авторизацией | Нужен аккаунт GitHub |
| Cloudflare Worker + KV | Настоящие звёзды, анонимно, живое. Бесплатно: 100 000 запросов/день, 10 мс CPU | Второй сервис, модерация и антиспам на владельце |
| **Форма + ручная публикация** ✅ | Посетителю не нужен аккаунт, спама на сайте не будет в принципе, владелец решает что показывать | Отзывы появляются не мгновенно |

Выбрана третья: для сайта-портфолио курирование — плюс, а не ограничение.
Сбор через **Google Forms** — аккаунт уже есть, бесплатно и без лимитов, есть поле-шкала.

## Что на странице `#/reviews`

Сводка со средней оценкой и числом отзывов, кнопка «Оставить отзыв», список карточек, ссылка
в подвале. Средняя считается из `items` автоматически. Оценка вне 1–5 обрезается — `9` до 5,
`0` до 1, разметка не ломается. Звёзды подписаны `aria-label` «оценка 4 из 5».

**Пока `formUrl` пуст, кнопки нет вовсе** — мёртвая кнопка хуже её отсутствия.

## Два правила, записанных в код и в README

**1. `items` уезжает пустым.** Выдуманных отзывов нет ни одного: на публичном сайте-портфолио
фальшивый отзыв — обман, а не «пример вёрстки». В тестах есть проверка на это: если однажды
фальшивка появится, тест упадёт. Тестовая фикстура живёт только в тесте.

**2. Обязательный вопрос о согласии.** Шестой вопрос формы — «Можно опубликовать ваш отзыв на
сайте?» с вариантами Да / Да, но без имени / Нет. Публиковать чужой текст и имя без явного
согласия нельзя. **Отзыв с ответом «нет» не попадает на сайт никогда**, даже если он хороший.

## Ссылка на форму

Akara прислал короткую `forms.gle/...`. В карту вставлен **канонический** адрес
`docs.google.com/forms/d/e/.../viewform`: короткий идёт через промежуточный редирект
`proxy.link.app`, то есть добавляет звено, которое может отвалиться.

Форма проверена: заголовок и все шесть вопросов на месте.

⚠ **Не сделано на стороне Akara:** в форме осталось обязательное поле «Электронная почта».
Человек не может оставить отзыв, не отдав почту, а для отзыва она не нужна.
Выключается в «Изменить настройки» → «Ответы».

## Чем проверяли

75 автопроверок: пустое состояние, появление кнопки после вставки ссылки, подсчёт средней
с обрезкой диапазона, подписи для скринридера, безопасные атрибуты внешней ссылки.
