# Сайт-дорожная карта «С нуля до AI Solutions Engineer»

## Context

Akara хочет перейти в профессию **AI Solutions Engineer** (T-shaped: широкая база Data Science /
ML / backend / cloud, глубокая специализация — проектирование AI-решений, RAG, агенты, MCP,
evals, production). ChatGPT выдал подробный промт-ТЗ на интерактивный сайт-дорожную карту.
Главное требование Akara поверх этого ТЗ: **достоверные ссылки** — курсы и модули должны
реально существовать, особенно на Khan Academy.

Проблема, которую решает сайт: без карты обучение превращается в бесконечный просмотр курсов.
Нужен один статический сайт с этапами, часами, проверяемыми критериями «готов идти дальше»,
прогрессом в localStorage и живым пересчётом сроков.

## Что расходится с промтом ChatGPT (и почему)

Каждое расхождение фиксируется прямо на сайте и в README — по правилу
`feedback-document-divergence-rationale`:

1. **Khan A1**: промт отправляет дроби/десятичные/отрицательные числа в `/math/pre-algebra`,
   где их нет. Добавляю `/math/arithmetic` с конкретными юнитами.
2. **Khan A2**: вместо «пройти Algebra 1 + Algebra 2» — точный список юнитов, нужных для ML
   (функции, наклон, экспоненты, логарифмы), со ссылками на реальные юниты.
3. Платные ресурсы (Udemy 100 Days, книги O'Reilly) остаются, но помечены «платно» и
   **не обязательны** — обязательный трек полностью бесплатный.
4. ResuMax и прочие рекламные вставки не включаются (прямое требование ТЗ).
5. Любой URL, который не отвечает 200 или переехал, заменяется на официальный аналог.
   Придуманных URL не будет: не проверил — не публикую.

## Протокол проверки ссылок

- **Khan Academy** — только через Chrome: навигация + `javascript_tool`, компактное извлечение
  `href` юнитов (`[...document.querySelectorAll('a[href^="/math/"]')]`), без выкачивания
  полного текста страницы.
- **Обычные сайты** (FastAPI, PostgreSQL, MDN, pandas, NumPy, pytest, Docker, HuggingFace,
  Anthropic/OpenAI/Google docs, sqlbolt, statquest, 3blue1brown, madewithml, cs50, cs229,
  fullstackdeeplearning, modelcontextprotocol, langchain, skills.github.com, British Council,
  Google tech writing) — `curl -o /dev/null -w "%{http_code}"` + `WebFetch` для сверки заголовка.
- **SPA/защищённые** — добираются в Chrome.
- Каждая ссылка получает поле `checked: "2026-08-23"`, сайт показывает «проверено 23.08.2026».
- Все внешние ссылки: `target="_blank" rel="noopener noreferrer"`.

## Функции интерфейса

- Главный экран: профессия, цель, **SVG-схема T-shaped** (горизонталь Data/ML/Backend/Cloud/
  Security/Business, вертикаль AI Engineering + Solution Architecture + Integrations), текущий
  этап, общий прогресс, срок окончания, переключатель часов (8/15/25 + произвольное),
  переключатель профиля, кнопка «Продолжить обучение».
- Режим **Сейчас / Далее / Позже** — карта не вываливает сотни задач как одинаково срочные.
- Карточки этапов: зачем, prerequisites, темы, обязательные и дополнительные ресурсы, задания,
  проект, критерии завершения, часы, статус, процент.
- Прогресс: чекбоксы, «пропустить как известное», заметки, даты старта/финиша, экспорт и импорт
  JSON, сброс с двойным подтверждением, `localStorage` (`asr:v1:*`).
- Навигация: поиск, фильтры обязательно/дополнительно, бесплатно/платно,
  теория/практика/проект, по трекам (Math, Python, Data, ML, Backend, AI, Cloud, Solutions),
  светлая/тёмная тема, адаптив, полная навигация с клавиатуры + видимый focus-ring.
- Отдельный блок **«Не попади в tutorial hell»** с правилами из ТЗ.
- Раздел диагностики (математика, Python, SQL, Git, английский, HTTP/API) → предложение, что
  можно пропустить.
- Таблица готовности к вакансиям: internship / Junior AI Engineer / Solutions Engineer /
  AI Solutions Engineer.

Дизайн: тёмно-синий + индиго, бирюзовые акценты, нейтральный светлый фон, полноценная тёмная
тема, спокойная типографика, без тяжёлых анимаций.

## Порядок работ

1. Создать папку и каркас файлов, `git init`, `.gitignore`, `.nojekyll`.
2. Собрать и **проверить** все ссылки (Khan — в Chrome, остальное — curl/WebFetch), сложить в
   `roadmap-data.js` с датами проверки.
3. Написать `roadmap-data.js` целиком: 10 этапов + 2 трека, без заглушек.
4. `index.html` + `styles.css` + `app.js`.
5. Локальная проверка (см. ниже), исправление найденного.
6. `gh repo create songhee24/ai-solutions-engineer-roadmap --public --source=. --push`,
   workflow Pages, включение Pages через API, ожидание деплоя, проверка живого URL.
7. Копия плана в `<repo>/.claude/plans/`, затем `claude-sync`.

- Все внешние ссылки открываются в новой вкладке, `rel="noopener noreferrer"`.
- После деплоя — открыть `https://songhee24.github.io/ai-solutions-engineer-roadmap/` в Chrome,
  убедиться, что CSS/JS подхватились (это и есть тест относительных путей).

## Риски и честные оговорки

- **Объём.** Это долгая сборка: ~10 этапов контента + ~80 проверенных ссылок. Заглушек не
  будет, но прогон длинный.
- **Реалистичность сроков.** 15 ч/нед на 18–24 мес при активной работе над loadex/bileli/pillar
  — это фактически вторая занятость. На сайте будет явный блок про это, а не рекламные обещания.
- **Ссылки живут.** Даты проверки нужны именно потому, что курсы переезжают; README объяснит,
  как обновлять `checked`.
