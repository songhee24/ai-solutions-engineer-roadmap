## Что это

Интерактивная дорожная карта обучения: **одна общая база — четыре возможных финала**
(Data Scientist, ML Engineer, AI Engineer, AI Solutions Engineer). Сайт же служит элементом
портфолио, поэтому к достоверности содержания требования как к продукту, а не к конспекту.

| Метрика | Значение |
|---|---|
| Разделов (этапы + треки) | 15 |
| Тем | 107 |
| Проверенных ссылок | 199 |
| Основной путь | 1609 ч новичку / 1246 ч разработчику |
| Дополнительные треки | 278 ч / 246 ч — **вне основного срока** |
| Срок при 15 ч/нед | ~24,7 мес новичку, ~19 мес разработчику |

Структура: этапы 0–9 плюс пять параллельных треков — A (математика) и B (английский) обязательные,
C (автоматизация), D (Data Science в глубину) и E (ML Engineering в глубину) дополнительные.

## Архитектура

**Статика без сборки:** HTML5 + CSS3 + vanilla JS. Ни зависимостей, ни шага сборки — открывается
как обычная страница, публикуется GitHub Actions на Pages.

```
index.html          разметка всех страниц; роутер показывает нужные секции
styles.css          токены темы (:root + [data-theme]), сетка, адаптив
app.js              роутер, рендер, прогресс, фильтры, экспорт/импорт
roadmap-data.js     ВСЁ содержание карты — единственный файл, который правят для контента
404.html · .nojekyll · .github/workflows/deploy-pages.yml
```

### Три принципа, на которых всё держится

**1. Содержание отделено от интерфейса.** `roadmap-data.js` — единственный источник контента.
`app.js` не знает ни одного названия темы. Правка содержания не требует чтения кода.

**2. Заголовки живут в данных, а не в разметке.** Урок раунда 10: заголовок был продублирован
в `<h1>`, правка `meta.title` никуда не выводилась, и на сайте висело старое название. Теперь
`renderHero()` заполняет заголовок и лид из `meta`.

**3. Необязательное помечается флагом, а не вычёркивается.** `stage.optional` исключает трек
из общего срока, из «Текущего этапа» и из блока «Сейчас / Далее», но оставляет его в карте.
Реализовано в `overall()`, `currentStage()` и `renderHorizons()`.

### Навигация

Клиентский роутер на хэше — за раз отрисован один экран. Главная 554 узла в DOM вместо прежних
6046 (раунд 8).

| Адрес | Страница |
|---|---|
| `#/` | Главная: цель, прогресс, срок, «Сейчас · Далее · Позже» |
| `#/roadmap` | Оглавление карты; при активном поиске — найденные темы |
| `#/stage/<id>` | Один этап, например `#/stage/track-english` |
| `#/diagnostics` · `#/throughline` · `#/method` · `#/tutorial-hell` · `#/jobs` · `#/reviews` | Остальные разделы |

Старые ссылки вида `#track-math` продолжают работать.

## Ключевые решения и почему именно так

**Ссылки Khan проверяются только браузером.** curl и WebFetch упираются в бот-защиту и отдают
`200` даже на выдуманный слаг `/math/totally-fake-course-xyz`. Проверка ими даёт ложноположительный
результат всегда. Единственный надёжный способ — открыть в браузере и прочитать заголовок после
отрисовки. Подробности: `khan-academy-link-verification` в памяти.

**Отзывы — форма плюс ручная публикация, а не бэкенд.** Оценка в `localStorage` осела бы в браузере
посетителя и владельцу была бы не видна. Из трёх вариантов (giscus, Cloudflare Worker, форма)
выбрана форма: посетителю не нужен аккаунт, спама на сайте не будет в принципе, а курирование для
портфолио — плюс. **`reviews.items` пуст: выдуманных отзывов нет ни одного,** и тест это охраняет.

**n8n основной, Make обязательный второй.** ChatGPT советовал ставить n8n выше Make. Проверка
реальной вакансии показала обратное: требуется Make, n8n не упомянут вовсе. Взяты оба — n8n даёт
механику, Make просят работодатели.

**Направления «AI Prompt Engineer» нет намеренно.** Заголовок в вакансиях упал на 30–40% с пика
2023, работа переехала в AI Engineer. Сам навык при этом вырос втрое и требуется в 78% AI-вакансий.
Это навык внутри этапа 6, а не пункт назначения.

**Адрес сайта и имя репозитория не менялись** при переформулировке названия — переименование
сломало бы ссылки, которые уже кому-то отданы.

## Как поддерживать

### Править содержание

Всё в `roadmap-data.js`. Схема ресурса:

```js
{ title, url, cost: "free"|"paid", lang, level, hours, required,
  scope: "Unit 4 из 19 — только этот юнит",   // ОБЪЁМ: сколько брать
  study: "что именно изучать",
  skip:  "что можно пропустить",
  checked: "2026-08-26" }                      // дата РЕАЛЬНОЙ проверки ссылки
```

Необязательные поля темы: `courseNote` (сколько брать из курса), `steps` (порядок действий),
`example` (пара «до/после»), `check` (критерий правильности).

**Добавили ресурс — откройте ссылку и поставьте настоящую дату в `checked`.** Курсы переезжают;
дата проверки — единственное, что отличает достоверную карту от свалки битых URL.

### Проверить все ссылки разом

```bash
node -e "global.window={};require('./roadmap-data.js');
  window.ROADMAP.stages.forEach(s=>s.topics.forEach(t=>t.resources.forEach(r=>console.log(r.url))))" \
| sort -u | while read u; do
    code=$(curl -sS -o /dev/null -L --max-time 25 -w '%{http_code}' "$u")
    [ "$code" = 200 ] || echo "$code  $u"
  done
```

Известные исключения, отвечающие только в браузере: British Council, Udemy, ai.google.dev,
O'Reilly, Reverso. Ссылки Khan этой проверкой **не проверяются** — см. выше.

### Добавить отзыв

```js
items: [{ name: "Имя или ник", role: "разработчик", rating: 5,
          text: "Текст отзыва.", date: "2026-08-26" }]
```

Средняя оценка считается сама. **Отзыв с ответом «нет» на вопрос о публикации не добавляется
никогда**, даже если он хороший.

### Тесты

Набор в jsdom (89 проверок на 26.08) лежит в скретчпаде сессии, а не в репозитории. При
возобновлении работы его стоит перенести в проект — сейчас он воспроизводится из документации
раундов, но не версионируется.
