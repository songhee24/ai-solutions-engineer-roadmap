# Путь с нуля до AI Solutions Engineer

Интерактивная дорожная карта: **Data Science — уверенная средняя база, AI Engineering и
проектирование AI-решений — глубокая техническая специализация, Solutions Engineering — умение
понять клиента, собрать систему и доказать её ценность.**

Статический сайт без сборки и зависимостей: HTML + CSS + vanilla JS. Открывается как обычная
страница, работает на GitHub Pages, прогресс хранится в `localStorage` браузера.

## Что внутри

- **10 этапов** (0–9) и **2 параллельных трека** — математика с полного нуля и технический английский.
- **Два профиля** — «Новичок» и «Разработчик»: у каждой темы своя оценка часов, срок пересчитывается.
- **Режимы нагрузки** — 8 / 15 / 25 часов в неделю (и произвольные значения). Основной режим — 15 ч/нед.
- **Сейчас · Далее · Позже** — вместо стены из сотен одинаково срочных задач.
- **Диагностика на входе** — отмечает уже известные темы и сокращает срок.
- **Проверяемые критерии** «Я готов двигаться дальше, если могу…» для каждого этапа.
- **Блок «Не попади в tutorial hell»** и таблица готовности к вакансиям.
- **Прогресс**: чекбоксы, «уже знаю», заметки, даты, экспорт и импорт JSON, сброс.

## Ориентировочные сроки

| Профиль | Всего часов | При 15 ч/нед |
|---|---|---|
| Новичок | ~1577 ч | ~24 месяца |
| Разработчик | ~1214 ч | ~19 месяцев |

Это объём материала, **а не обещание трудоустройства**. Реальный срок зависит от того, сколько
кода вы пишете сами.

### Как менять содержание

Всё содержание лежит в **`roadmap-data.js`** и отделено от интерфейса. Схема описана
комментарием в начале файла:

```js
{
  id: "stage-4-fastapi",
  title: "FastAPI и Pydantic: свой сервис",
  en: "FastAPI and Pydantic",
  track: "backend",                    // math | python | data | ml | backend | ai | cloud | solutions | english
  kind: "practice",                    // theory | practice | project
  hours: { novice: 35, dev: 20 },      // две оценки часов
  required: true,
  resources: [{
    title: "FastAPI — Tutorial, User Guide",
    url: "https://fastapi.tiangolo.com/tutorial/",
    cost: "free",                      // free | paid
    lang: "en", level: "Средний", hours: 22, required: true,
    study: "что именно изучать",
    skip: "что можно пропустить",
    checked: "2026-08-23"              // дата, когда ссылку реально открывали
  }],
  task: "практическое задание после ресурса"
}
```

Добавили ресурс — **откройте ссылку и поставьте настоящую дату в `checked`**. Ссылки на курсы
переезжают; дата проверки — единственное, что отличает достоверную карту от свалки битых URL.

## Запуск локально

```bash
python3 -m http.server 8765
# затем откройте http://localhost:8765/
```

Открывать `index.html` двойным щелчком тоже можно — скрипты подключены обычными тегами,
без ES-модулей, поэтому `file://` не ломается.

## Прогресс: экспорт, импорт, перенос

Прогресс лежит в `localStorage` под ключом `asr:v1` и **никуда не отправляется**.

- **Экспорт** — кнопка внизу страницы, скачивает `ai-solutions-engineer-progress.json`.
- **Импорт** — та же панель, выберите ранее выгруженный файл.
- **Сброс** — кнопка требует двух нажатий подряд.

Чтобы перенести прогресс на другое устройство или в другой браузер: экспорт → импорт.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает и публикует сайт при каждом пуше в `main`.
В настройках репозитория **Settings → Pages → Source** должно быть выбрано **GitHub Actions**.

Все пути в разметке относительные (`./styles.css`), поэтому сайт корректно работает и в корне
домена, и в подпапке проекта (`https://<user>.github.io/<repo>/`).

## О достоверности ссылок

Каждая ссылка в карте открывалась вручную и имеет дату проверки (**2026-08-23**), которая видна
прямо в интерфейсе под ресурсом. Отдельно проверялась структура курсов Khan Academy: их разделы
переименовывались, поэтому карта ссылается на **реально существующие юниты**, а не на темы «по памяти».

Одно важное расхождение с типовыми списками тем: в курсе Khan Academy **Pre-algebra нет дробей,
десятичных и отрицательных чисел** — эти разделы живут в курсе **Arithmetic**. Карта учитывает это
и отправляет вас именно туда.
